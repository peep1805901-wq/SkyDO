================================================================================

2. Extract: unzip VeloJets-Android.zip
3. Open Android Studio
4. File → Open → select extracted VeloJets-Android folder

7. Click green "Run" button (▶️)
8. See the app launch! 🎉

   → Get from Firebase Console (see SETUP_GUIDE.md)
